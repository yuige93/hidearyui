# 宇宙课程表

家长和孩子共用的课程与生活计划工具。保留蓝紫色宇宙主题、彩色课程卡片和火箭图案，让一周的安排看得清楚，也方便一起调整课后与周末计划。

![宇宙课程表预览](docs/preview.jpg)

## 功能

- 周计划与月历，支持切换周、回到今天及周末视图。
- 新增、编辑、删除个人安排，支持每周重复、时间冲突提示与撤销。
- 每日或每周学习任务；打卡收集星星，记录商量好的奖励兑换。
- 数学、英语与国学示例成长路线；经典诵读进度单独保存。
- 浏览器本地保存、JSON 备份导出与打印。

课表、校名和昵称均为虚构示例。成长路线是可调整的参考内容，初始任务与进度为空。

## 安装与运行

需要 Node.js >=22.13.0，建议 Node.js 24。

```sh
npm ci
npm run dev
```

打开终端显示的地址（通常为 `http://127.0.0.1:5173/`）。

```sh
npm test          # 日期、冲突、重复任务和本地保存检查
npm run build    # TypeScript 检查并生成静态网页
npm run preview  # 查看构建结果
```

## 保存范围

计划仅保存在当前浏览器的 localStorage。刷新后保留，浏览器清理数据、无痕模式或更换网址可能使计划不可用。不同设备不会同步；同一网址的多个标签页以最后保存为准。

在“备份与说明”中可导出 JSON。目前没有备份导入功能，导出文件适合保留记录；不要依赖它自动恢复计划。页面不上传任务、课程或进度，也不连接共享数据接口。公开版不包含服务端登录或云同步。

## 按自己的课程调整

- `examples/timetable.ts`：虚构的周课表。课程时段与页面 `lessonSlots` 的标记保持一致。
- `lib/school-calendar.ts`：默认周一至周五上课；节假日、暑假与调课需自行配置。
- `app/page.tsx`：名称、昵称、界面与交互；学校课程通过示例配置修改。
- `components/growth-map.tsx`：示例成长路线。

学校课程在界面中只读；工作日个人安排从 16:00 开始，周末支持 08:30—20:00。课表时间为虚构示例，使用前请按实际安排调整。

## 静态部署

`npm run build` 生成 `dist/`，可交给支持静态文件的网站托管服务。Vite 使用相对资源路径，便于放在一个产品目录下。网页需要 HTTPS 才适合在手机中添加到主屏幕；公开版没有离线缓存。

GitHub Pages 可托管这类静态网页；该功能与 GitHub 源码仓库的公开设置分别管理。见 [GitHub Pages 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)。

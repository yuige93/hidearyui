# 宇宙课程表

家长和孩子共用的课程与生活计划工具。保留蓝紫色宇宙主题、彩色课程卡片和火箭图案，让一周的安排看得清楚，也方便一起调整课后与周末计划。

![宇宙课程表预览](docs/preview.jpg)

## 功能

- 周计划与月历，支持切换周、回到今天及周末视图。
- 新增、编辑、删除个人安排，支持每周重复、时间冲突提示与撤销。
- 每日或每周学习任务；打卡收集星星，记录商量好的奖励兑换。
- 数学、英语与国学示例成长路线；经典诵读进度单独保存。
- 浏览器本地保存、JSON 备份导出与打印。
- 2026年国家节假日、调休补班标记与24节气。
- 主屏幕安装、离线页面缓存；可自托管跨设备同步、版本冲突处理与服务端备份。

本版按2026-10-06核对的最新实现整理，数据格式版本4、同步协议版本2。课表、校名和昵称均为虚构示例；成长路线是可调整的参考内容，初始任务与进度为空。

## 安装与运行

需要 Node.js >=22.13.0，建议 Node.js 24。

```sh
npm ci
npm run dev
```

打开终端显示的地址（通常为 `http://127.0.0.1:5173/`）。

```sh
npm test          # 日期、冲突、重复任务和本地保存检查
npm run build    # TypeScript 检查并生成静态网页
npm run preview  # 查看构建结果
```

## 保存范围

默认运行时，计划保存在当前浏览器的 localStorage。刷新后保留，浏览器清理数据、无痕模式或更换网址可能使计划不可用。默认模式的不同设备不会同步；同一网址的多个标签页以最后保存为准。自托管模式使用同一份家庭状态并保留浏览器缓存。

在“备份与说明”中可导出 JSON。目前没有备份导入功能，导出文件适合保留记录；不要依赖它自动恢复计划。默认模式不上传任务、课程或进度。只有明确设置 `VITE_SYNC_ENDPOINT` 才连接自己的同步实例；本仓库不包含任何现成家庭数据或生产访问配置。

## 按自己的课程调整

- `examples/timetable.ts`：虚构的周课表。课程时段与页面 `lessonSlots` 的标记保持一致。
- `lib/school-calendar.ts`：2026年国家节假日与节气；学校调课与暑假另行配置。国家补班只标记“调休上班”，不代替学校指定课程。
- `app/page.tsx`：名称、昵称、界面与交互；学校课程通过示例配置修改。
- `components/growth-map.tsx`：示例成长路线。

学校课程在界面中只读；有学校课程的日期个人安排从16:00开始，无课的节假日与周末支持08:30—20:00。课表时间为虚构示例，使用前请按实际安排调整。

## 自托管跨设备同步

每个家庭使用一个独立实例。复制 `.env.example` 为 `.env`，设置写入账号 `PLANNER_USERNAME` / `PLANNER_PASSWORD`；可另设只读账号。保留 `VITE_SYNC_ENDPOINT=/api/state` 后执行：

```sh
npm run build
npm start
```

打开自己的本机地址（示例配置为 `http://127.0.0.1:5180/`），浏览器会要求登录。服务只监听本机；跨设备使用时，应通过自己配置的 HTTPS 反向代理访问同一实例。登录由各家庭实例自行管理。

`data/` 保存状态与备份，不纳入源码。同步沿用最新版 revision 冲突检测、增量合并、原子写入、每日及逐版本备份；一个实例共享一份计划，不提供不同家庭的多租户服务。详情见 [服务端说明](server/README.md)。

## 日历来源

2026年假期与补班按[国务院办公厅通知（官方转载）](https://www.beijing.gov.cn/zhengce/zhengcefagui/202511/t20251104_4258873.html)核对；节气按[香港天文台2026年日历](https://www.hko.gov.hk/tc/gts/time/calendar/pdf/files/2026.pdf)核对。其他年份的调休日期需在官方通知发布后更新，不自动推测学校补课。

## 静态部署

`npm run build` 生成 `dist/`，可交给支持静态文件的网站托管服务。Vite 使用相对资源路径，便于放在一个产品目录下。手机安装及 service worker 需要 HTTPS（本机 localhost 也可）。首次加载成功后缓存页面、图标和当前构建的资源；离线时使用本地计划，不缓存同步接口响应。静态部署使用默认本地模式即可。

GitHub Pages 可托管这类静态网页；该功能与 GitHub 源码仓库的公开设置分别管理。见 [GitHub Pages 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)。
